ESTRUTURA DE SEGURIDAD (FIRESTORE RULES)

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Clientes: lectura pública, escritura solo autenticada
    match /artifacts/{appId}/public/data/clientes/{clienteId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    
    // Pedidos: lectura y escritura pública (para menús no autenticados)
    match /artifacts/{appId}/public/data/pedidos/{pedidoId} {
      allow read, write: if true;
    }
    
    // Referidos: lectura y escritura pública
    match /artifacts/{appId}/public/data/referidos/{referidoId} {
      allow read, write: if true;
    }
  }
}

FLUJO DE DATOS

1. Cliente entra al menú → menu-core.js
2. Firebase lee datos de Firestore → clientes/{id}
3. Cliente agrega producto al carrito → cart.js
4. Cliente finaliza pedido → cart.js
5. Pedido se guarda en Firestore → pedidos/{REF}
6. Pedido se envía por WhatsApp → wa.me/{telefono}
7. Admin muestra pedidos → admin.js
8. Admin actualiza estado → admin.js
9. Admin gestiona productos → admin.js


COMANDOS UTILES

# Desplegar hosting
firebase deploy --only hosting

# Desplegar reglas de Firestore

# Desplegar todo
firebase deploy

# Ejecutar localmente
firebase serve

# Registrar un cliente
python main.py

# Migrar extras (Node.js)
